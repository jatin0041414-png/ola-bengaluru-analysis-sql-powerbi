# Ola Bengaluru Ride Booking Analysis | SQL Server & Power BI : 
## Project Overview
This project analyzes Ola ride-booking data from Bengaluru to understand booking trends, revenue performance, customer behavior, vehicle performance, and ride cancellations.
## Tools Used
- **SQL Server:** Data querying, aggregation, CTEs, subqueries, and window functions.
- **Power BI:** Interactive dashboards, KPI tracking, and data visualization.
## Key Analysis Areas
- Booking status and cancellation analysis
- Revenue and booking value analysis
- Vehicle-wise performance comparison
- Customer booking behavior
- Ride distance and booking trends
## Key Skills Demonstrated
SQL querying, data analysis, business KPI analysis, analytical problem-solving, and dashboard development.
## Project Objective
To transform ride-booking data into meaningful business insights and demonstrate practical skills relevant to an entry-level Data Analyst role.
